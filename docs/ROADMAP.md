# Roadmap and acceptance gates

## Gate 1: Typing core
- Validate every Myanmar Unicode key, vowel, combining mark, backspace, grapheme deletion and display order.
- Test English shift/caps, cursor, selection, enter action, symbols, emoji, phone number fields.
- Add Android and iOS tests and test on physical devices.

## Gate 2: Productivity
- Add encrypted local personal dictionary, opt-in snippets, text shortcuts, user-controlled clipboard pins, cursor swipe, keyboard height presets where allowed.

## Gate 3: Language intelligence
- Myanmar syllable segmentation, prediction models, Myanmar/English detection and transliteration, offline inference.

## Gate 4: Advanced features
- Android speech recognition; iOS host-app dictation with copy/paste; explicit consent.
- Translation APIs; offline fallback, privacy disclosures, metering, cost controls.
- Swipe typing; currency pad; encrypted optional backup and recovery.

## Gate 5: Customer launch
- Threat model and security audit, accessibility audit, privacy policy, store disclosures, localization, crash monitoring without text logging, load and battery testing, release signing, TestFlight / Play testing, review and approval.
